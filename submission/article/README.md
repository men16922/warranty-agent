# Medium 아티클

발행 대상: **Medium — Google Cloud** 퍼블리케이션

| 파일 | 무엇 |
|---|---|
| `medium-article.md` | 본문. Medium 에디터에 붙여 넣는다 |
| `../gallery/*.png` | 본문에 들어갈 그림 (번호가 본문의 `[Image N]` 자리와 맞는다) |

## ⚠️ 붙여 넣을 때

- Medium은 마크다운 파일 **임포트**를 지원한다(`Import a story`). GitHub raw URL을 주면
  이미지까지 같이 끌어온다 — push 후 raw 링크를 쓰는 게 가장 빠르다.
- 코드 블록은 붙여 넣은 뒤 Medium 에디터에서 ``` 로 다시 감싸야 서식이 산다.
- **캡션을 지우지 말 것.** 그림마다 *"실물에서 온 것"*이라고 적혀 있고, 그게 이 글의 신뢰다.

## ⛔ 이 글에서 하지 말 것

- 측정하지 않은 수를 쓰지 않는다. 본문의 모든 숫자는 `docs/evidence/`에 원본이 있다.
- 실패를 숨기지 않는다. 이 글의 절반은 **우리가 틀린 이야기**이고, 그게 논지다.
