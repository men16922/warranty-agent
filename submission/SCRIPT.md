## 0. 한 문장

> **에이전트 함대가 밤새 뭘 했는지, 아침에 한 페이지로 안다.**

로그는 전부 `completed`라고 말한다. 그런데 서비스는 어젯밤과 똑같이 느리다.
화면에 반드시 남아야 하는 것은 **`improved`가 따로 있는 표**다. 나머지는 곁가지다.

⭐ **이 영상이 이전 판과 결정적으로 다른 세 가지**
1. **성공 장면이 있다** — `990.04 → 674.17ms` · `recovered`. 이전엔 `improved 0`뿐이라
   *"한 번도 도움이 안 되는 에이전트"*로 읽혔다.
2. **실패 장면이 진짜다** — `674 → 990ms`로 실제로 나빠지고, 롤백하고, **롤백 후에도 다시 재고**,
   서버에서 트래픽을 되읽어 확인한다.
3. **엔딩이 자기 고백이다** — 이 시스템이 자기 논지에 네 번 걸린 이야기.
   ⛔ **지어낸 겸손이 아니라 08-30에 실제로 일어난 일이고**, 넷 다
   *"로그는 초록인데 나아진 게 아니었다"*의 변주다.

## 3. ⛔ 다시 만들 때 반드시 지킬 것

재현 절차 전체는 [`vo/README.md`](vo/README.md). 여기는 **함정만** 적는다.

### ① 데스크톱을 찍지 말 것

⛔ 실제 화면 촬영은 **버렸다.** Chrome 창이 여럿이라 `front window`가 내 창을 안 가리켰고,
**세 번 연속으로 개인 창이 프레임에 들어왔다.** 키 입력도 엉뚱한 창으로 갔다.
⇒ headless 렌더링(HTML→PNG)은 결정론적이고 **남의 화면을 안 건드린다.**

### ② 목소리를 바꾸면 길이가 바뀌고, 그것이 4분 상한을 건드린다

ElevenLabs Jackson은 macOS `say`의 **1.41배**로 읽는다. 그대로 갈았으면 **4:29 — 실격**이었다.
⇒ 군더더기만 잘라 214초로 줄이고 `assemble.py`의 `TEMPO=1.08`을 얹었다.
⚠️ **논지 문장은 하나도 안 건드렸다.** 깎을 곳은 군더더기지 논지가 아니다.

### ③ 조치 전에 지표 창을 확인할 것

[`vo/p95.sh`](vo/p95.sh)가 **120초 창 안에 점이 있는지** 본다. 없으면 신호가 `null`이고,
게이트가 검증 불가로 막는다 — 정상 동작이지만 촬영할 그림이 아니다.
⚠️ **두 리비전이 동시에 트래픽을 받으면 값이 흔들린다.** 한쪽으로 100% 모으고
창이 한 번 지나간 뒤에 찍는다.

### ④ 숫자를 내레이션에 못 박지 말 것

⛔ 08-29 리허설이 이미 잡았고, 08-30에 **또 걸렸다.** 지표는 실행마다 다르다.
성적표 비트처럼 **숫자가 논지인 자리**만 값을 부르고, 나머지는 방향으로 말한다.

### ⑤ 타이머를 줄이고 싶은 유혹

`VERIFY_DELAY_S`를 줄이면 촬영이 편해진다. **그러지 말 것.**
⛔ 그것이 정확히 자기 고백 ①이다 — 45초로 뒀더니 재측정 창이 **조치 이전을 물었고**,
개선이 혼합으로 지워졌다. 지금 값은 `VERIFY_WINDOW_S + 15`이고 **가드가 지킨다**(M-281).

## 4. ⛔ 하지 말 것 — 금지 문장

| 문장 | 왜 안 되나 |
|---|---|
| *"41건을 처리했고 회복률 56%"* | **측정 안 한 수다.** 한 번 걸렸다(T8-2) |
| *"이 조치가 $X를 아꼈다"* | 트래픽 전환은 과금 리소스를 안 만든다. **0이 맞는 답이다** |

| *"완전 자동 운영"* | 게이트의 절반은 **자동으로 안 하는 것**이다 |
